# Photos App (Kotlin Android Prototype)

This is a prototype Android app built with Kotlin and Jetpack Compose.

## Features
- Basic gallery UI with local image selection
- Search by filename
- Supported Android API levels 29 through 34
- Uses modern Compose UI and Coil image loading

## Build Instructions

1. Open the `photos-app` folder in Android Studio.
2. If Gradle wrapper is not installed, install Gradle 8.3 or newer.
3. Sync the project and run on an Android device or emulator.

## Notes
- This is a local prototype, not connected to Google Photos.
- App icon uses a Photos-style adaptive icon.
- Camera and storage permissions are requested for image access.
